# BranchCheck Obligation Taxonomy (v0.4 freeze)

This taxonomy is the semantic contract for the next experiments. An obligation is executable only when the backend advertises the required capability; unsupported obligations are `NotApplicable`, never inferred as failures. The generic baseline column records what can detect a supplied terminal failure, while the guidance column states the intended witness-construction value.

## Relation rules

1. A relation may fail only for a capability declared by the backend profile.
2. A relation must compare a branch observation with an independently constructed reference observation or an explicitly declared boundary, not with a hard-coded issue ID.
3. A `Pass` at creation does not discharge a continuation obligation.
4. A generic baseline detection is retained as evidence; it is not treated as a BranchCheck failure of exclusivity.
5. New backend adapters must map to an existing family before a new family is introduced.

## Required fields for every future family entry

`name`, `required capability`, `branch contract assumption`, `state`, `reference construction`, `legal witness continuation`, `observation points`, `expected relation`, `known historical cases`, `current executable backend`, `generic baseline detectability`, and `guidance rationale`.
